## S1 之前必须定

- [ ] **WebP 编码器**：优先 libwebp 静态链接（无 DLL）；需要实测构建时间、许可证与产物依赖。若必须附带 DLL，先征得用户同意；否则回退 JPEG/PNG。
- [ ] **thumb 自定义协议**：在真实 WebView2 中测 `thumb://` 的 150 张冷/热加载；确认 CSP、缓存头与 Tauri 2 的 Windows URL 形式。
- [ ] **pack 分段策略**：默认 1 GiB/段是否合适；20 万张约 4-10 GB，需要段数、打开句柄与压缩窗口的实测。
- [ ] **pHash 细节**：32×32 DCT → 16×16 中位数二值化；用真实样本确认阈值（建议 6/256）与误报率。
- [ ] **主色算法**：OKLab vs Lab、k-means 迭代上限、4/8 色权重存 u8 的精度是否足够。
- [ ] **解码上限**：最大像素数/最大分配（如 1 GiB）与超大图降采样策略。
- [ ] **EXIF 方向**：缩略图/pHash 应用方向；查看器显示与裁剪坐标如何统一。
